The Silent Negotiator
A Real-Time Multimodal AI System for Negotiation Support
📌 Overview
Developed at the Kyoto University Graduate School of Management, this project explores the feasibility of using AI to analyze emotions and deception cues in real-time. It functions as cognitive augmentation, providing negotiators with probabilistic indicators to enhance situational awareness without replacing human judgment.

🚀 Key Features
Multimodal Integration: Syncs video, audio, and text streams for holistic analysis.
Linguistic Analysis: Scans transcriptions for patterns like hedging and distancing language.
Vocal Stress Tracking: Monitors pitch and energy as proxies for psychological arousal.
Real-Time Dashboard: A Streamlit interface offering diagnostic visibility of behavioral signals.

🛠️ Technology Stack
Vision: DeepFace & OpenCV (Emotion detection).
Audio: OpenAI Whisper (Transcription).
Text: TextBlob & DistilBERT (Sentiment & NLP).
Framework: Evaluated via the Technology Readiness Level (TRL) scale.
📊 Findings
The prototype currently occupies an Intermediate TRL. While individual AI modules are mature, system-level integration faces challenges with hardware-dependent latency and data synchronization.
